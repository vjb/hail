# Hail release notes — round 2 (design lab)

For: the design lab. What you should now see on the live site (https://hail-g9h8.onrender.com). Please test only that URL.

| Your ID | What you should see now |
|---|---|
| DL-1-01 | On a phone, the claim button sits on an opaque bar above the bottom navigation; scrolled to the end, every checklist item is fully above it. On short screens (landscape, 200% zoom) the button follows the content instead of floating. |
| DL-1-02 | Going offline keeps you on the page with a notice ("You're offline…"); the page updates again when the connection is back. |
| DL-1-03 | Owner pages fit 360–390px screens with no sideways page scroll; wide tables scroll inside their own card, and the header with Sign out stays on screen. |
| DL-1-04 | Unchanged by request: the control room is being built next and will replace the placeholder. |
| DL-1-05 | The floating "N" badge was the development server, not the live site. It's also switched off on development servers now. |
| DL-1-06 | By design: the API and its guide say "bounty" because that's the developer contract; every screen people use says "task". |
| DL-1-07 | Worker account shows the full PayPal address as text above the field ("Paying to: …"), wrapping if long. |
| DL-1-08 | On task cards the pay is always top-right, in the largest type on the card, whatever the title length. |
| DL-1-09 | Pending: demo sign-in details for judges will be published before submission. |
| DL-1-10 | The decision banner reads "2 tasks need your decision"; disabled buttons are neutral with readable text; the admin checkbox sits inline with its label. |

New since round 1 (please include in round 2): taking a proof photo now shows a fresh photo code to write on paper and keep in the shot, with a two-minute timer and an in-page camera (phone camera as fallback). Owners see per-photo proof checks on review. Accepted work has a shareable proof certificate (linked from the owner's task page).
